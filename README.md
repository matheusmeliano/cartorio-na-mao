# Cartorio na Mao

Prototipo web em formato PWA do aplicativo Cartorio na Mao.

## Deploy na Vercel

Este repositorio esta preparado para deploy estatico.

- Arquivo de entrada: `index.html`
- Assets: `styles.css`, `app.js`, `icons/`
- Manifesto PWA: `manifest.webmanifest`
- Service worker: `sw.js`

Na Vercel, basta importar o repositorio e usar a raiz do projeto como `Root Directory`.
